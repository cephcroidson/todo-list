# 📝 My To-Do List

A simple, responsive To-Do List web application built with HTML, CSS, and JavaScript.

## 🚀 Features

- Add tasks
- Complete tasks
- Edit tasks
- Delete tasks
- Due dates
- Task priorities
  - 🟢 Low
  - 🟡 Medium
  - 🔴 High
- Search tasks
- Filter tasks
  - All
  - Active
  - Completed
- Clear completed tasks
- Remaining task counter
- Task statistics
- Empty-state messages
- Dark mode
- Responsive design
- LocalStorage persistence

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub
